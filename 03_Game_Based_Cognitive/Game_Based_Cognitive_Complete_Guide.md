# 🎮 Capgemini Game-Based Cognitive Assessment: Complete Guide & Hacks

The Game-Based Cognitive Round in Capgemini Exceller is powered by the **Aon / cut-e platform**. You will be given **4 games** (approx 5–6 minutes each, total 20–25 minutes).

Unlike conventional aptitude tests, there are **no formulas to memorize**, but games test your **working memory, spatial orientation, executive control, and deductive logic under rapid time limits**.

---

## 🕹️ Game 1: Switch Challenge (Deductive Reasoning)

### What is it?
- You are shown 4 symbols at the top (e.g., Circle, Triangle, Square, Cross) in a specific order: `[1, 2, 3, 4]`.
- At the bottom, the symbols are rearranged.
- In the middle, there is an operator box with a 4-digit code (e.g., `3 1 4 2`) or multiple levels of operators.
- You must find which operator correctly rearranges the symbols, or deduce the final output sequence.

### 💡 Winning Strategy & Hacks:
1. **Understand what the code means**:
   - If the code is `3 1 4 2`:
     - It means: Position 1 takes what was at position 3. Position 2 takes what was at position 1. Position 3 takes what was at position 4. Position 4 takes what was at position 2.
2. **Track just ONE distinctive symbol**:
   - Don't try to look at all 4 symbols at once!
   - Pick the most visually distinct symbol (e.g., the Cross).
   - Check where it started $\rightarrow$ where it ended $\rightarrow$ eliminate 2 to 3 wrong option choices in 2 seconds flat!
   - If two options remain, trace a second symbol.

## 🕹️ Game 2: Grid Challenge (Dual-Task Working Memory)

### What is it?
This is the most notorious game. It tests your ability to hold short-term memory while performing a secondary cognitive distraction task:
1. A dot appears on a grid (e.g., cell (2, 3)) for 1 second.
2. Immediately, an unrelated symmetry question pops up: *"Is this image symmetrical across the vertical axis? [Yes / No]"*. You have 2-3 seconds to answer.
3. Another dot appears on the grid (e.g., cell (1, 1)).
4. Another symmetry question pops up.
5. This repeats for 3 to 5 steps.
6. At the end, you are presented with an empty grid and asked: *"Click the positions of the dots in the EXACT order they appeared."*

### 💡 Winning Strategy & Hacks:
1. **Use Mental / Spatial Storytelling or Fingers**:
   - Don't rely on passive visual memory because the symmetry test will wipe it out.
   - Encode coordinates into numbers or physical points:
     - E.g., Think "Top-Right, Center, Bottom-Left" or "3, 5, 7".
     - Discreetly touch your fingers on the desk corresponding to grid quadrants.
2. **Symmetry Test Rule**:
   - Spend at most 1.5 seconds on the symmetry question. Pick quickly; do NOT let the symmetry question break your memory loop of the dots.

## 🕹️ Game 3: Motion Challenge (Spatial Planning & Pathfinding)

### What is it?
- A grid/maze containing a ball, obstacles/blocks, and a hole/target.
- You must slide blocks or roll the ball to reach the goal in the **minimum number of moves possible**.
- Each level has a strict move limit (e.g., "Solve in 4 moves").

### 💡 Winning Strategy & Hacks:
1. **Work Backward from the Target**:
   - Look at the target hole first.
   - Ask: *"From which square can the ball enter the hole?"*
   - Then: *"How do I get the ball to that predecessor square?"*
2. **Do Not Move Impulsively**:
   - Taking 15 seconds to plan the whole path mentally and executing it in 4 clicks will yield a much higher cognitive score than moving randomly and backtracking.

---

## 🕹️ Game 4: Digit Challenge / Quick Calc (Numerical Speed)

### What is it?
- You are shown a target number (e.g., `18`) and a set of digits (e.g., `2, 4, 6, 8`) with basic operations (`+`, `-`, `*`).
- You must select digits to satisfy the equation within 10–15 seconds per round.

### 💡 Winning Strategy & Hacks:
1. **Look for Multiples**:
   - If the target is large (e.g., 42), find which two available numbers multiply close to it (e.g., $6 \times 7$).
2. **Odd/Even parity**:
   - If the target is odd, you need at least one odd number in addition/subtraction.

## 🎯 Important Mindset for Cognitive Games
- **Accuracy > Rushing**: The scoring algorithm heavily penalizes erratic, rapid wrong guesses. Maintain a calm, deliberate rhythm.
- **Device Setup**: Use an external mouse on a stable desk; do not use a laggy laptop trackpad!
