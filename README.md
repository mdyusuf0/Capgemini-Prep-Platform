## ⚡ Quick Start Guide

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or later)
- [MongoDB](https://www.mongodb.com/) running locally on port `27017` (or MongoDB Atlas connection URI)
- Git

### 1. Clone the Repository
```bash
git clone https://github.com/mdyusuf0/Capgemini-Prep-Platform.git
cd Capgemini-Prep-Platform
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
cp .env.example server/.env
```

### 4. Seed the Complete Question Bank
Populate MongoDB with 1,695+ questions, candidate debugging challenges, and assessment profiles:
```bash
npm run seed
```

### 5. Launch the Development Environment
Starts both the Vite client (`http://localhost:5173`) and Express backend (`http://localhost:5000`) concurrently:
```bash
npm run dev
```

### 6. Login Credentials
Once the server is running, log in with the administrator account:
- **Email**: `admin@capgemini-prep.com`
- **Password**: `Admin@123456`
